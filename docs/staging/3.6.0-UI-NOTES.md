## Scope rule

- Dossier sheet (`renderNpcDossier` header), standing history only with 2+ points.

## Not verified (needs live Lumiverse)
- Container queries (`@container`) inside Lumiverse's drawer and own window (supported by current Chromium/WebKit; an old WebView would fall back to the single-column layout).

- Mobile Lumiverse, the float panel resized live, screen readers.
