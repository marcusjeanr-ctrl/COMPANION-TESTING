# UI stabilization evidence

Tests run the actual frontend bundle in Chromium with a mock Lumiverse bridge and
payload/HTML generated by the actual backend fixture. They do not test live host
permissions, network providers, actual WebView sandboxing or persisted host data.

The long compound name fixture is within the current report-name length limit.
Before the fix, its study row has 363px scroll width in 276px available width;
the full note is present. The defect is wrapping, not missing tracking data.
`overflow-wrap:anywhere` is scoped to existing spell rows (also reused by sword
techniques). No data cap, prompt, locale, status rule or stored record changes.

The floating panel's default width and left offset put its right edge at 462px on
a 320px viewport. Restored desktop coordinates can put the whole panel off screen.
Viewport size limits and clamping on restoration, drag, resize and enlarge keep
controls accessible. The resize listener is removed on cleanup; it adds no polling,
model call, tracker refresh or persistent write. Ordinary wide-screen sizes and
user-selected modes remain. Browser resize clamping alone does not rewrite saved
preferences. A subsequent deliberate move/resize uses the existing save path.

Six Chromium tests cover full study note/name display, viewport containment,
restored geometry/viewport change, popout return, labels/settings/test zone and
Internal States tabs/collapse. For local runs install playwright==1.62.0 and its
Chromium, or set CHROMIUM_PATH to an installed Chromium. Run with Node 22:

```sh
python3 tools/test_ui_browser.py
```

The standard Node suites still exercise the original four demo worlds and six HUD
examples for five primary card formats. Real RP card files and a Lumiverse test
instance are not available. Screenshots and measurements are local test artifacts,
not public previews or certification. Density/text-size/theme variations and
system-wide coverage are recorded in the final Phase 2 report.
