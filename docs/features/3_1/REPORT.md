# 3.1.0 RC staging feature verification

Branch: `staging/features-3.1`. Baseline: `540df20f602bd475b9149c1ab28aa705e391f72d` (3.0.10 RC).
No live Lumiverse instance has been used. Chromium uses a mocked host.
Runtime source is the checked-in `dist/backend.js` and `dist/frontend.js`.
Only their marked translations/guides are generated by `tools/embed_i18n.py`.

## 1. Consistency checker

Optional advisory table: missing readable HUD, raw backward clock/date, and
opposite explicit `Field: active|inactive|enabled|disabled [at rest]` directives.
Start input is retained only in the existing shared continuity-index traversal;
matching cached start-handler rules are read without loading additional lore.
Conditional rest checks require an explicit resting HUD field. Unsupported prose
rules are deliberately unverified; no rules engine, corrections or writes.
Warnings can include intentional rewinds: they are advisory, never corrections.
Source changes: both runtime files and four translation dictionaries (English
is the source key); new `tools/test_features_3_1.cjs` registered in the suite.
Checks cover missing HUD, raw time regression, start/card setting conflict,
non-rest exclusions and disabling. All 52 suites and release identity passed.

Initial benchmark baseline → feature 1: warm panel 63.04 → 61.33 ms;
cold panel 284.24 → 347.57 ms (+22.3%); parse 0.5568 → 0.5714 ms;
response 0.7823 → 0.8343 ms (+6.6%); prompt construction 0.3767 → 0.3717 ms.
These are single cloud measurements, not demonstrated causal slowdowns.
Prompt lengths unchanged (15,291 / 19,213 characters). Final alternating paired
measurements will check the >5% observations before acceptance.

existing in-game age. Guesses retain their uncertainty label. Old activity is
secondary inside a closed Last reported activity disclosure; current reports
remain visible. No stored `where`, timestamps or presence rules change.

byte-identical input. All 52 suites/release checks passed. English source keys
and all four dictionaries updated and embedded. See per-feature benchmark table.
