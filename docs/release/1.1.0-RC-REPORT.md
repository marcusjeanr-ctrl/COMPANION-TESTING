## 4. Supported without modification

Header/wall detection, numbered calendar, Shown/True hidden power on Mana and Sword lines, Race/Origin/Age, Demon Eye and Curse/Blessing lines, canon clock and event ledger, reporter-driven systems (Gear and containers, Finances, Holdings, Quests, Agenda, Minds, knowledge, secrets, family records, relationships), context injection and its de-duplication.

## 5. Confirmed incompatibilities and root causes

1. **Visual rows ignored by the guard and Chronicle.** `hmsMarkBlocks` treats any ─/━/═ fence pair as an inline block; Visual's two ━━━ dividers enclosed every stat row.
2. **Compact skills unread.** Readers only knew `Sword Style:` / `Magic Tiers:` / `Voiceless Casting:`; Compact merges them into `Skills:` with short tiers.
3. **Compact mana/Touki.** Mana parser split only on labelled `| Reserve:`; Compact's row is positional and carries Touki after `·`.
4. **Compact place reversed.** Arrowless `Spot, Region (Continent)` was split as general→specific; "current place" became the region; a false "First time at Asura Kingdom (Central Continent)" appeared.
5. **Slots joined by `·` in Classic.** Only Visual lines split on `·`, so `Standing: … · Faction: …` hid the faction and `Guild: F` (Classic/Compact), while Visual read `F` as a faction.
6. **Arc null.** `parseHud` only recognised `Arc` / `Current Arc`.
7. **Wounds on Condition.** Wound readers only knew `Injuries:`; v1.1 has none, so the extension decided the card did not keep wounds and asked the model for its own `injuries` list (a competing tracker), while the wound showed as a condition named "Cracked rib — Treated".
8. **Guard noise.** Style switches, Compact's on-change Memory/Equipment, and v1.1 slots that end by rule (Training, Present, Active Paths, canon lines, Turning Point) were reported as dropped lines.
9. **Smaller readers.** Languages split inside "(Fluent, reads)"; period only from the old `Year: | Day:` format; Imperial/Divine had no step on the world card ladder; technique reach ignored Visual rows (icon + bold label).
10. **Panel display.** The raw HUD copy inside the Companion card is a live `### WORLD STATE ###` block that the card's display regex could redraw.

## 8. Simulation and regression results

- `replay_check.cjs` on the 60-reply session with the real v1.1 lorebook (1,297 entries): **0 problems** (no duplicate quests/agenda/gear, player never tracked twice, request injected once, no repeated Chronicle moments).
- Per-reply audit of the same session: wounds follow the HUD in every style; 0 replies with false dropped lines (6 style switches shown as template changes; Condition, Training, Present shown as cleared); world card identical across styles at every reply; faction rank Page → Tutor followed.
- Chronicle (1.0.1 → RC): false "First time at Asura Kingdom (Central Continent)" gone; story start names the arc; new milestones for Magic Tiers, Faction and Sword Style steps.
- `compare_backends.cjs` 1.0.1 vs RC on synthetic sessions for Re:Zero, Overlord, COTE, Mushoku Living World, Undertale, Dark Souls and the older Six-Sided format: **identical panel data, narrator request and Chronicle** at every reply once the changed settings default is neutralised. Skyrim differs only in `Companions (Whelp)` now being "member" (panel and request).

## 9. HUD and world-state verification

Classic, Panel, Visual and Compact produce the same world card (date, period, mana, reserve, Touki, casting, schools, styles, languages, guild), the same Spellbook ranks, the same technique reach, the same current place and the same factions. ## 10. Narrator, reporter, context injection

Request injected exactly once (smoke and replay). For v1.1 the `injuries` schema and rules are no longer sent (−694 chars/turn on the simulated session, 18,884 → 18,190). No new instructions were added to the request. The HUD stays authoritative; Companion still never asks for a competing HUD.

## 11. Persistence, attribution, de-duplication

No saved-data format change and no migration. HUD line keys are unchanged (`era / arc` keeps its key, so saved pins still match their line). Replay checks found no duplicates or self-tracking. Factions are keyed by name; the guild rank no longer creates a stray "F" record.

## 14. Universal compatibility

All new readings are gated by shape, not card name: the labelled-`·` rule only splits when a `Label:` follows; Compact skills require every part to carry a Mushoku rank word and a school icon/element or ⚔️; divider bands require an untitled fence pair followed by more HUD lines (titled blocks and blocks above the wall are unchanged); the Compact place rule runs only on Mushoku HUDs without arrows. Two deliberate cross-card effects: the default dropped-line "self-clearing" list gained labels (Training, Present, Active Paths, canon-clock lines, Turning Point), and a bracketed rank on a membership label now means member (Skyrim).

## 15. Limitations and risks

- **No live Lumiverse run.** All results are from the real backend/frontend code on synthetic chats and the real card data; real model output may vary in spacing and labels beyond what was tested.
- **Panel display order** (V): whether Lumiverse runs Companion's HUD card or the card's "HMS Panel" regex first is untested. Either result is display-only; with Companion's HUD card on, players may see Companion's card instead of the framed panel (Settings → HUD card off shows the card's panel).
- Not tracked as data (shown on the HUD card only): Training session counts, HUD Bonds stages, Present list, faction time windows, family plots and household authority, renown spread.
- Compact: `Skills:` with Shown/True is not read; Compact steps in Sword Style/Magic Tiers are not Chronicle milestones (Classic/Visual/Panel are); birth date is not on Compact lines.
- Arc spelling check stays off for `Era / Arc` (to keep pin keys stable).
- A user who customised Settings → dropped-line "self-clearing" keeps their own list and will not get the new defaults.

### Live smoke checklist (Lumiverse ≥ 1.2.0, HMS Reporter preset)

1. Install/update from the branch; panel title reads 1.1.0 RC; an existing 1.0.1 chat opens with its pins, Chronicle and trackers intact.
2. New v1.1 chat, start with `HUD: Classic` and a `Social:`/`Faction:` line: world card shows date, period, mana/reserve, Touki, schools, styles, languages; Factions shows the faction as member with its rank; Guild shows its letter rank.
3. Get hurt: Wounds shows the Condition wound and follows Raw → Treated → Healing → gone; the request (Diagnostics) has no `injuries` schema.
4. `[HUD = VISUAL]`, then `[HUD = COMPACT]`, then `[HUD = CLASSIC]`: no "dropped lines" warning on switches; world card and Spellbook unchanged; Compact turns without Memory/Equipment raise nothing.
5. Finish a Training line into a promotion: Chronicle shows the Magic Tiers / Sword Style step; the Training line shows as cleared.
6. `HUD: Panel` with the card's regex allowed: note which display wins (Companion card or framed panel), that nothing is drawn twice, and that "Show the HUD as text" is plain text. Repeat with Settings → HUD card off.
7. Reload the page: panel state, pins and Chronicle persist.
8. One other card (Re:Zero or Overlord): panel and HUD card behave as in 1.0.1.
