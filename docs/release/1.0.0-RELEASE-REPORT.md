## 9. Issues found and outstanding risks
Fixed during this review (on `release/1.0.0`):
- **Find lost keystrokes in large chats** (3.6.0 regression; display only). Each keystroke redrew the panel and replaced
  the box; letters typed during the ~50 ms redraw were lost. Now only the result list updates.

Risks needing your decision (not fixed: no confirmed failure, and fixing them would be speculative):
1. **No live Lumiverse test** of any of 3.5–3.6 or 1.0 (install/update, WebView, persistence across reloads, own window, mobile).
2. **Version goes down (3.6.0 → 1.0.0).** If Lumiverse's Update compares versions, existing installs may not be offered
   1.0.0. Test on an existing install; if needed, reinstall from source, or ship the manifest as 4.0.0 named "HMS Edition 1.0".
3. **Name variant in Minds**: an NPC named the player's name plus one word (player "Marcus", NPC "Marcus Brightwater", not
   in the party) would be merged into the player. Not seen in the exports.
4. **Cards other than Six-Sided World** were not replayed. Run `replay_check.cjs` on a Re:Zero, COTE or Overlord export.
5. Layout uses CSS container queries (two columns, side rail, gear rows); an old WebView falls back to one column.
6. Ctrl+K may be taken by the host or browser; the ⌕ button always works.
7. RC policy: AGENTS.md keeps "RC" until live acceptance; the 1.0.0 label assumes that acceptance happens first.

## 12. Promotion and rollback (proposed, not done)
Tags first (non-destructive):
```
git tag -a v3.4.0-prod  4cb5deb -m "Production before 1.0.0 (3.4.0 RC)"
git tag -a v3.5.0-rc    0318b1a -m "Final 3.5.0 candidate"
git tag -a v3.6.0-ui-rc bf80da9 -m "Final 3.6.0 UI candidate"
git tag -a v1.0.0-rc    e3a841e -m "HMS Edition 1.0.0 candidate"
git push origin v3.4.0-prod v3.5.0-rc v3.6.0-ui-rc v1.0.0-rc
```
Promote: open a PR `release/1.0.0` → `main` and merge it (fast-forward possible: `main` is an ancestor). Then verify:
```
git fetch origin main && git diff --stat e3a841e origin/main   # must be empty
node tools/run_tests.cjs && node tools/check_release.cjs        # CI validate must pass on main
node tools/replay_check.cjs <export> Marcus <card>              # 0 problems
git tag -a v1.0.0 <main head> -m "RPG Companion HMS Edition 1.0.0" && git push origin v1.0.0
```
Then the GitHub release (and package via `tools/package_rc.py`), after the live checks below.
Rollback: `git revert -m 1 <merge commit>` on `main` through a PR, or restore the tree of `v3.4.0-prod` in a revert
commit; no force-push. Players: Update (or reinstall from source) brings 3.4.0 back; saved data is compatible both ways
(no schema change).
