# Cyberpunk Living World V1.5 compatibility

Base: release/1.4.0 at 9627633c65e9f361c9daff4db539e1898f1c0956.
Input: Cyberpunk: Living World V1.5 character card (1,781 lorebook entries).

## Scope

Only the Cyberpunk world-card reader, its coverage labels, and its frontend
render branch change. All other runtime code is byte-identical to the base,
including tracking, persistence, HUD upkeep, prompt injection, other world cards,
shared lore lookup, and Compact cyberware history lookup. The uploaded character
card, release version, preset, stylesheets and manifest are unchanged.
No new model calls, storage writes, polling or history scans.

## Output inventory

| Card output | Panel behavior and checks |
| --- | --- |
| Date, location | Existing shared HUD display; unchanged |
| Identity, arc, Game Mode | Existing identity/pronouns/arc; adds Leveling and Branch Run |
| Eddies, Humanity/Psyche, Street Cred/Reputation | Existing values, bands and deltas retained; zero-valued fields tested |
| Level, XP, Attribute Points, Perk Points | Reads and displays explicit values; never spends or awards points |
| Vitals: HP, Armor, optional RAM | Current/max resources and armor, including zero; omitted resources remain absent |
| Attributes | All five; both Technical and legacy Technical Ability canonicalize to the existing label |
| Build | Existing strengths and weakness retained |
| Five attribute Perks rows | Names, attribute groups, levels, new/level-up marks; legacy single Perks row retained |
| Compact Perks counts | Total and per-attribute counts; never invents names or new-perk marks from counts |
| Relic | Named perks, existing lore hover lookup and unspent Relic Points |
| Cyberware | Pipe-separated implants, body systems, tiers through T5++, Mk names; legacy commas and untiered period chrome retained |
| Netrunning | Existing net level and deck retained |
| Arsenal | Named weapons and tiers using the existing lore lookup |
| Faction, Bonds, Heat, Passenger | Existing standing, bonds, hunted factions and overwrite retained |
| Goal, Condition | Displays current HUD text without creating quests or modifying injuries |
| Changes | Existing progress, checkpoints, changed-canon notices plus Back on canon |
| Canon Clock | Both next-event and turning-point rows retained together |
| Living Canon | Canon reference, Canon Ledger and dated World event rows |

Rule-only modules (Living Canon, Canon Modes, HUD Styles, Leveling Modes, Play As)
remain narrator-owned. Only their explicit HUD output is displayed. Lore entries
for NPCs, places, gear, perks, roles, events and world rules continue through the
existing shared lore system; their gameplay semantics are not reimplemented by
this display patch.

## Verification

- The new four-style V1.5 regression failed on the original reader, then passed.
- Classic, Visual, Compact and Panel synthetic HUDs pass; legacy V1.4 checks pass.
- Removal/absence, untiered chrome, tier upgrades, perk upgrades, Compact
  uncertainty and Living canon have targeted regressions.
- Actual worldPanel -> frontend smoke checks pass in modern, storybook and
  minimal looks, including zero resources and Compact chrome carry-forward.
- node tools/run_tests.cjs: all 12 checks pass locally on Node 24.22.1.
- Runtime scope comparison and git diff --check pass.
- Real-browser layout checks could not run: Chromium was absent and the browser
  download returned invalid archives. Mock DOM render success is not browser
  layout certification. Live Lumiverse play/install/reload was not tested.

Compact deliberately contains perk counts rather than identities. The panel
therefore shows those counts until the HUD prints named perks again. The existing
60-HUD Compact chrome carry-forward behavior is unchanged. Any pre-existing
tracking or HUD-upkeep limitations remain outside this patch's scope.
