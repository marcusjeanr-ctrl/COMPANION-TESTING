# Cyberpunk Living World V1.8 compatibility

Base: release/1.4.0 at e09d006. Input: Cyberpunk: Living World V1.8 character card
(1,958 lorebook entries). The card's description, first message, eight catalog pages and
all 74 entries of lorebook section 00 (HMS System & Commands) were read in full; the
rest of the lorebook was checked by title, key and entry format.

## What V1.8 prints, and how it is read

| Card output | Panel behaviour |
| --- | --- |
| Header (Date, ◆ location, Identity, Arc, Game Mode) | As V1.5, plus `Capri Compatible` on Game Mode |
| Eddies, Humanity, Street Cred | As V1.5 |
| `Level: N/60 \| XP: N% \| Attribute Points \| Perk Points` | World card as V1.5; `XP: Max` read; the You panel now uses the HUD's percentage and level |
| `Vitals: HP a/b \| Armor N \| RAM a/b` | World card as V1.5; HP and RAM now feed the vitals bars |
| Attributes, Build, perk rows, Compact perk counts | As V1.5 |
| Cyberware with tiers and body systems | As V1.5; on Compact, a new implant is marked new on the turn the line returns |
| Netrunning, Arsenal, Relic, Faction, Bonds, Heat, Passenger, Goal, Condition | As V1.5 |
| `TT Coverage: Silver / Gold / Platinum` | New: world card row |
| `Changes: … (done), … (goal)` with indented checkpoints | `(done)`/`(goal)` read as status |
| Canon Clock, Living Canon lines | As V1.5 |

Item hover text (implants, perks, Relic perks, weapons) resolves from each item's own entry
(`[24A Cyberware — …] Cyberware: Name [System]`, `Perk: Name`, weapon entries).

## Fixed in the shared pipeline (every card)

- A `━━━` rule pair that opens the HUD is a frame, not a block (Visual styles that wrap
  the whole HUD lost their clock and other main-line reads).
- The "HUD lines to carry" narrator note no longer asks back lines a card removes by its
  own rule (configured self-clearing labels, Heat, one-shot checkpoint and canon lines,
  Compact's Cyberware). Genuinely dropped lines are still reported.
- `XP: N%` / `XP: Max` and `Vitals: HP a/b | RAM a/b` are read; `Net Level N` is not a level.
- `HUD: <style>` after a comma on a start line is recognised.

## Verification

- Synthetic four-turn V1.8 chats in Classic, Visual and Compact, plus a Level 60 chat
  with Passenger, Relic, Faction, TT Coverage, Changes and both canon clocks, run through
  the full pipeline with the card's lorebook: all values read; no HUD line is rewritten.
- New regression in `tools/test_tracking_audit.cjs`; it fails on the previous backend.
- All suites pass. Earlier real chats (Mushoku, Six-Sided, Cyberpunk V1.0) compare
  identical to the previous backend apart from the purely added fields.
- Not tested: live Lumiverse play with the V1.8 card, or the Panel style's display scripts.
