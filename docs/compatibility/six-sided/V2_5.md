# Six-Sided World v2.5 (Preset Friendly) compatibility

Base: release/1.4.0 at 8bd03d4. Input: *Mushoku Tensei RPG — Six-Sided World v2.5 Preset Friendly*
character card (description 22.5k chars, first message, 12 alternate greetings, 77 display regex
scripts, embedded lorebook of 1,017 entries). The description, the first message, every greeting
and every regex script were read in full, and so were the lorebook's 50 rule entries
([HUD], [Mt central control], [Mushoku tensei start handler], [campaign control]). The rest of the
lorebook (characters, magic, arcs and arc memories) was checked by title, key and format; its
content matches the v2 Standalone Lorebook.

## What v2.5 prints, and how it is read

| Card output | Companion |
| --- | --- |
| `### WORLD STATE [PANEL] ###`, `### WORLD STATE [COLLAPSED] ###` | **New:** read as the HUD (before: no HUD at all in Panel/Collapsed). The header is kept as written, so the card's display scripts still draw it |
| `### 🌐 WORLD STATE ###` (Visual), `### 🌐 Language ###` translation | As before; a translation block is not a second HUD |
| `HUD Style: …` row, `[HUD = COLLAPSED]` | Style read from the row, the header tag or the command; Collapsed handled like Panel |
| `Armored Dragon Calendar: K414, Rainveil 12, Stoneday \| Time: Late afternoon` | **New:** Themed, Familiar (`April 12, Thursday`) and Numbered (`Month 4, Day 12, Stoneday`) dates; weekday kept; a time in words gives an approximate hour for the clock, sky and elapsed time (same-day word changes are never called a rewind) |
| Season, Current Scene, Rudeus Mode, Guide, HUD Style, Calendar Profile | **New** world card rows (season chip, scene, settings chips) |
| `Current Arc: Arc 2-B: Hearth & Home [MT-ARC:2-B]`, `[MT-ARC:Sandbox]` | Marker read and left off the title; branch routes and marker-only lines placed on the saga |
| Magic `Elementary … Emperor, God` (Beginner/Imperial/Divine aliases) | Kept as written (before: rewritten to Beginner/Imperial/Divine). Drifted Novice/Apprentice/Expert become Elementary/Advanced. Sword ranks unchanged |
| The card's row order (date, Season, Location, Current Arc, Current Scene, Race, …, NPCs Present, Narrative Mode) | Upkeep keeps v2.5's order (before: reordered to v2's) and puts a dropped Current Arc back after Location |
| `NPCs Present:` | Read as the present cast; the player is taken off it with the label kept |
| `Injuries: site — Raw / Treated / Magic-Healed / Lasting / Permanent` | Wounds apart by `;` or `,`; Lasting shown as lasting damage; world card shows each wound with its care stage |
| `Magic Tiers: 💧 Water — Advanced \| 🪨 Earth — Intermediate`, `Voiceless Casting: Water, Earth, Fire` | Icons left off school names (the spell list matches the lorebook); a school list on Voiceless Casting counts as voiceless; a note after a style name is left off it |
| `Race/Origin/Age: Human / Native / 12 (born K404, Deepfrost 12)` | Read, and written as `Race: … \| Origin: … \| Age: …` (the card's Panel draws `Race`); a named birth month counts for the age |
| Compact `Skills: 🌪️ Wind — Elementary · ⚔️ Sword God Style — Beginner` | Read as schools and styles with their ranks |
| Party Mode: `Player: Name` followed by that player's rows | Rows belong to their player: never reordered across records, never read onto a shared sheet; your world card is your own record |
| `Mushoku_Save`: two fenced blocks (WORLD STATE, SAVE NOTES) | Both blocks come through intact (before: the fences between them were stripped, in every card) |

Rules the v2.5 card no longer has are not enforced on its HUDs: the Training session counts,
Bonds limit and stages, Renown tiers, Saint-needs-Touki, and "Game Mode the start never chose"
(v2.5 lets the bot set Original Character, Sandbox, Rudeus's Role and similar).

## Fixed in the shared pipeline (every card)

- A Visual HUD with bold labels (`📅 **Armored Dragon Calendar:**`) now has its clock
  (Six-Sided v2 Visual export: clock was null).
- An empty fence around the Companion's block is removed only when it really is empty; the
  closing and opening fences of two blocks in a row are left alone.

## The card's lorebook keys (not changed by the Companion)

All 1,017 entries set `use_regex: true`. In Lumiverse that makes every key a regular expression:
the 435 keys written as `/…/` never match (the slashes are taken literally), and plain keys such
as `[MT-ARC:2-B]` become character classes that match almost any text, so arc entries fire on
nearly every turn. This is the card's data, and play is not altered here. A fixed copy (keys
converted, content untouched) can be made on request.
